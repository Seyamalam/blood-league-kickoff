# Gameplay Recording Handoff

The editor needs one file from the player:

`trailer/input/gameplay-master.mp4`

## Fastest acceptable recording

1. Launch the production desktop build.
2. Set the game to fullscreen at 1920×1080.
3. Start recording before pressing **Enter the Pitch**.
4. Play one uninterrupted run for approximately ten minutes.
5. Demonstrate as many mechanics as possible, but prioritize natural play.
6. Stop recording after a boss, death, victory or other clear ending.
7. Do not trim, recompress or narrate the recording.

## Ideal second recording, if time permits

Record another five minutes focused on anything missing from the first run—especially a goal, Count Goalkeeper, an ultimate or a strong upgrade draft.

Name it:

`trailer/input/gameplay-pickups.mp4`

## Recording quality

- MP4 or MOV
- 1920×1080
- 60 fps preferred
- Game audio included
- Microphone disabled
- No desktop notifications
- No performance overlay

The raw files are intentionally excluded from Git because video footage is large.
